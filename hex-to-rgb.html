Convert HEX to RGB — Free Color Converter

HEX and RGB are the two most common ways to represent colors on the web. A HEX color code is a six-character string of hexadecimal digits (0-9, A-F) preceded by a hash symbol, like #C49A2A. Each pair of digits encodes one of three color channels: red, green, and blue. RGB expresses the same channels as decimal numbers ranging from 0 to 255, making it easier to read and manipulate in code. Converting between the two formats is a matter of translating between base-16 and base-10 number systems.

The HEX to RGB Formula

A hex color like #C49A2A is split into three pairs: C4, 9A, and 2A. Each pair is converted from hexadecimal to decimal. C4 in hex equals 12 × 16 + 4 = 196 (Red). 9A equals 9 × 16 + 10 = 154 (Green). 2A equals 2 × 16 + 10 = 42 (Blue). The result is rgb(196, 154, 42). Three-digit shorthand codes like #F0A are expanded by doubling each digit: #FF00AA.

When to Use HEX vs RGB

HEX codes are compact and widely used in CSS, HTML, and design tools. They are the standard for web stylesheets and brand guidelines because they are concise — six characters encode a full color. RGB is more readable for programmatic use: when you need to manipulate individual channels, calculate color distances, or generate colors dynamically in JavaScript, RGB makes the math straightforward. CSS supports both formats natively, so the choice often comes down to preference. If you need transparency, use rgba() which extends RGB with an alpha channel from 0 to 1.

Frequently Asked Questions
What is hex color?

A hex color is a six-digit hexadecimal code preceded by # that represents a color. Each pair of digits encodes the red, green, and blue channels as values from 00 (0) to FF (255). For example, #FF0000 is pure red, #00FF00 is pure green, and #0000FF is pure blue. Hex is the most common color format in CSS and HTML.

How do I convert hex to RGB?

Split the six-digit hex code into three pairs. Convert each pair from hexadecimal to decimal: the first pair is Red (0-255), the second is Green (0-255), the third is Blue (0-255). For example, #C49A2A becomes R:196, G:154, B:42. Use our converter above for instant results.

What is #000000 in RGB?

#000000 in RGB is rgb(0, 0, 0), which is pure black. All three color channels — red, green, and blue — are at their minimum value of zero, producing the absence of light.

What is #FFFFFF in RGB?

#FFFFFF in RGB is rgb(255, 255, 255), which is pure white. All three color channels are at their maximum value of 255, combining to produce the brightest possible color in the additive RGB model.
